# PlatePay - الدفع الذكي عبر لوحة السيارة

## Problem
يعاني مستخدمو خدمات السيارات، مثل المطاعم ومحطات الوقود ومواقف السيارات، من الحاجة إلى الدفع اليدوي في كل مرة، مما يزيد وقت الانتظار ويجعل تجربة الدفع أقل سلاسة.

## User
السائقون الذين يستخدمون خدمات السيارات بشكل متكرر، مثل الـ Drive-thru ومحطات الوقود ومواقف السيارات، والتجار الذين يقدمون هذه الخدمات.

## Solution
نساعد المستخدم على الدفع بسهولة من خلال التعرّف الآلي على لوحة السيارة، والتحقق من موقع الهاتف والتفويض المسبق وحدود الإنفاق، ثم تنفيذ عملية الدفع عبر بوابة دفع إلكترونية.

## Differentiator
ربط هوية المركبة بعملية الدفع لتوفير تجربة دفع سلسة دون الحاجة إلى إخراج البطاقة أو إدخال بيانات الدفع في كل مرة.

## MVP features (build only these)
- تسجيل المستخدم وربط لوحة السيارة بحسابه.
- قراءة لوحة السيارة تلقائياً من صورة أو كاميرا.
- ربط وسيلة دفع تجريبية وتحديد حدود الإنفاق.
- التحقق من موقع الهاتف ومطابقته مع موقع الخدمة.
- محاكاة عمليات الدفع والموافقة أو الرفض.
- عرض سجل المعاملات والإيصالات.
- دعم أنواع متعددة من الخدمات المعتمدة على السيارات.

## Vision (do not build yet)
تطوير منصة دفع ذكية تجعل السيارة وسيلة للتعرّف على المستخدم وربط الخدمات بعملية دفع آمنة وسلسة، لتصبح تجربة الدفع أسرع وأسهل في مختلف الخدمات التي تعتمد على المركبات.

## Stack
- Frontend: React with Vite
- Backend: Node.js and Express
- Database: MongoDB Atlas with Mongoose
- Payments: Stripe test mode only, if needed

## Rules
- Build one feature fully, then the next.
- Small steps. Explain each change.
- Never put secrets in code. Use Replit Secrets or .env.
- Do not add features that are not in the MVP list.
